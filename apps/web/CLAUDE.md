# LogYourBody Web

Canonical assistant guidance lives in the repo-root [`AGENTS.md`](../../AGENTS.md).

This app is the Next.js marketing, legal, support, billing, and first-party API surface for LogYourBody. It is not a Fusion Starter / Vite / React Router SPA.

- Identity: Jovie Better Auth (`logyourbody-web`)
- Product data: Neon via first-party bearer APIs
- Native iOS never connects to Postgres
- Do not restyle the marketing footer here (LYB-18 owns that)
