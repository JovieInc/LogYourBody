# iOS app configuration

`Config.xcconfig` is ignored and contains environment-specific configuration.
Bootstrap a secret-free development config from the repository root:

```bash
pnpm ios:bootstrap-local-config
```

The app needs Jovie OAuth (`AUTH_ISSUER`, `AUTH_CLIENT_ID`, and
`AUTH_REDIRECT_URI`) plus the first-party API URL (`API_BASE_URL` and
`API_EXPECTED_HOST`). Production release config is generated by the protected
release workflow and uses server-only Neon data through the first-party API.

Never commit a real `.xcconfig` file or credential. Rebuild after changing a
local configuration file so Xcode reloads the values.
